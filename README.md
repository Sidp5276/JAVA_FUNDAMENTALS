# Java Fundamentals & Data Structures Practice Repository

## Overview

This repository contains my Java Fundamentals, Object-Oriented Programming (OOPs), Data Structures, Collections Framework, and Problem-Solving practice programs. The primary goal of this repository is to build a strong foundation in Core Java and Data Structures & Algorithms, which are essential for Software Development Engineer in Test (SDET), QA Automation, and Software Engineering roles.

The repository includes topic-wise organized Java programs, coding exercises, pattern problems, and commonly asked interview questions covering beginner to intermediate-level concepts.
